Bloque 6 · Introducción

Integrales trigonométricas e irracionales

Senos y cosenos elevados a potencias, tangentes al cuadrado, raíces… No están en la tabla, pero con una identidad trigonométrica o un cambio de variable bien elegido se convierten en integrales que ya sabes hacer.

1 Las identidades que vas a necesitar

Casi todas las integrales trigonométricas de este curso se resuelven transformando el integrando con alguna de estas identidades, hasta que aparece una integral inmediata o un cambio de variable sencillo.

Fundamental\(\operatorname{sen}^2 x + \cos^2 x = 1\)
Tangente\(1 + \operatorname{tg}^2 x = \dfrac{1}{\cos^2 x}\)
Ángulo doble\(\operatorname{sen} 2x = 2\operatorname{sen} x\cos x\)
Bajar el cuadrado\(\operatorname{sen}^2 x = \dfrac{1-\cos 2x}{2} \qquad \cos^2 x = \dfrac{1+\cos 2x}{2}\)
💡Pregúntate siempre primero: ¿aparece una función y su derivada? (por ejemplo \(\operatorname{sen} x\) y \(\cos x\)). Si es así, es un cambio de variable del Bloque 3. Las identidades se usan cuando eso no ocurre a simple vista.

2 Producto de seno y coseno, y potencias con su derivada

Si aparece una potencia de \(\operatorname{sen} x\) multiplicada por \(\cos x\) (o al revés), es una integral inmediata de tipo potencia, porque \(\cos x\) es la derivada de \(\operatorname{sen} x\):

Regla

\[\int \operatorname{sen}^n x\,\cos x\,dx = \frac{\operatorname{sen}^{n+1} x}{n+1} + C \qquad \int \cos^n x\,\operatorname{sen} x\,dx = -\frac{\cos^{n+1} x}{n+1} + C\]

Ejemplo resuelto

Calcula \(\displaystyle\int \operatorname{sen}^4 x\,\cos x\,dx\)

Cambio \(u = \operatorname{sen} x\), \(du = \cos x\,dx\):

\[\int u^4\,du = \frac{u^5}{5} + C = \frac{\operatorname{sen}^5 x}{5} + C\]

3 Potencias impares de seno o coseno

Si el seno (o el coseno) está elevado a una potencia impar, se separa un factor y el resto se transforma con \(\operatorname{sen}^2 x + \cos^2 x = 1\). Así aparece la derivada que hace falta para el cambio de variable.

Ejemplo resuelto

Calcula \(\displaystyle\int \operatorname{sen}^3 x\,dx\)

Separamos un seno: \(\operatorname{sen}^3 x = \operatorname{sen}^2 x\cdot \operatorname{sen} x = (1-\cos^2 x)\operatorname{sen} x\).

Cambio \(u = \cos x\), \(du = -\operatorname{sen} x\,dx\):

\[\int (1-\cos^2 x)\operatorname{sen} x\,dx = -\int (1-u^2)\,du = -u + \frac{u^3}{3} + C\]

Deshacemos el cambio: \(\displaystyle\int \operatorname{sen}^3 x\,dx = -\cos x + \frac{\cos^3 x}{3} + C\)

4 Potencias pares: bajar el cuadrado

Si la potencia es par, separar un factor no sirve. Se usan las fórmulas que «bajan el cuadrado» y convierten el integrando en algo con \(\cos 2x\), que ya es inmediato.

Ejemplo resuelto

Calcula \(\displaystyle\int \cos^2 x\,dx\)

\[\int \cos^2 x\,dx = \int \frac{1+\cos 2x}{2}\,dx = \frac{x}{2} + \frac{1}{2}\cdot\frac{\operatorname{sen} 2x}{2} + C = \frac{x}{2} + \frac{\operatorname{sen} 2x}{4} + C\]

Del mismo modo: \(\displaystyle\int \operatorname{sen}^2 x\,dx = \frac{x}{2} - \frac{\operatorname{sen} 2x}{4} + C\).

Ejemplo resuelto · La tangente al cuadrado

Calcula \(\displaystyle\int \operatorname{tg}^2 x\,dx\)

Sumamos y restamos 1 para que aparezca \(1+\operatorname{tg}^2 x\), que es la derivada de \(\operatorname{tg} x\):

\[\int \operatorname{tg}^2 x\,dx = \int \big(1+\operatorname{tg}^2 x - 1\big)\,dx = \operatorname{tg} x - x + C\]

5 Integrales irracionales

Son las que tienen raíces. Muchas son inmediatas si se escriben como potencias de exponente fraccionario; otras se resuelven con un cambio de variable que elimina la raíz.

Como potencia\(\displaystyle\int f'(x)\,\sqrt{f(x)}\,dx = \int f'(x)\,f(x)^{1/2}\,dx = \frac{2}{3}f(x)^{3/2} + C\)
Raíz en el denominador\(\displaystyle\int \frac{f'(x)}{\sqrt{f(x)}}\,dx = 2\sqrt{f(x)} + C\)
Arcoseno\(\displaystyle\int \frac{dx}{\sqrt{1-x^2}} = \operatorname{arcsen} x + C\)
Cambio que elimina la raízSi aparece \(\sqrt{x}\) o \(\sqrt{ax+b}\), se llama \(t\) a la raíz: \(t=\sqrt{x}\Rightarrow x=t^2,\ dx = 2t\,dt\).
Ejemplo resuelto · Como potencia

Calcula \(\displaystyle\int x\sqrt{x^2+1}\,dx\)

La derivada de \(x^2+1\) es \(2x\): ponemos el 2 dentro y \(\frac12\) fuera.

\[\int x\,(x^2+1)^{1/2}\,dx = \frac12\int 2x\,(x^2+1)^{1/2}\,dx = \frac12\cdot\frac{(x^2+1)^{3/2}}{3/2} + C = \frac{(x^2+1)^{3/2}}{3} + C\]

Ejemplo resuelto · Cambio que elimina la raíz

Calcula \(\displaystyle\int \frac{dx}{1+\sqrt{x}}\)

Cambio \(t=\sqrt{x}\): \(x = t^2\), \(dx = 2t\,dt\).

\[\int \frac{2t}{1+t}\,dt = \int \left(2 - \frac{2}{1+t}\right)dt = 2t - 2\ln|1+t| + C\]

Deshacemos el cambio: \(\displaystyle\int \frac{dx}{1+\sqrt{x}} = 2\sqrt{x} - 2\ln\big(1+\sqrt{x}\big) + C\)

🔍 Pregunta de indagación

Una misma integral, como \(\int \operatorname{sen} x\cos x\,dx\), puede dar \(\frac{\operatorname{sen}^2 x}{2}\) o \(-\frac{\cos^2 x}{2}\) según el camino. ¿Cómo pueden ser correctas las dos? ¿Qué nos dice esto sobre la constante C?

Concepto clave

Relaciones · Equivalencia. Las identidades trigonométricas permiten escribir la misma función de formas distintas, y elegir la que se puede integrar.

Habilidad ATL

Pensamiento estratégico: antes de calcular, decidir qué transformación convierte la integral en una que ya sabes hacer.

Conexión TdC

Si dos resultados aparentemente distintos son ambos correctos, ¿qué significa que una respuesta matemática sea «la» respuesta?
